Positioning

What this project is: a reproducible, interpretable MaxEnt IRL study on public Porto taxi data. Its state is the incoming edge, so turn features are Markov; gradients are computed exactly by finite-horizon soft value iteration; and every result is reported with confidence intervals against Dijkstra-Shortest, Dijkstra-Fastest, a myopic classifier and a popularity-weighted baseline. It does not claim a new learning algorithm.
"Our contribution is an open, readable and statistically honest benchmark of MaxEnt IRL for route choice, including where it does not beat simple baselines."

📐 Detailed MDP Formulations per Literature Review

A rigorous side-by-side comparison of the state spaces, action bounds, transition kernels, reward functions, and policy objectives across each investigated paper.

Ziebart et al. (2008) AAAI '08
Maximum Entropy Inverse Reinforcement Learning
\(\mathcal{M} = \langle \mathcal{S}, \mathcal{A}, \mathcal{P}, \mathcal{R}_{\theta}, \mathcal{S}_{goal} \rangle\)
\(\mathcal{S}\)
State Space: Road segments of the road network (first-order Markov decision process over the map).
\(\mathcal{A}\)
Action Space: Next adjacent road segment from the current one.
\(\mathcal{P}\)
Transitions: Deterministic: choosing a segment moves the vehicle onto it.
\(\mathcal{R}\)
Reward Function: Linear in road features, \(\mathcal{R}_\theta = \theta^T f\) (road type, speed, lanes, turn types).
\(\pi^*\)
Trajectory Probability: \(P(\tau \mid \theta) = \frac{1}{Z(\theta)} \exp(\theta^T f(\tau))\); gradient is expert minus expected feature counts via backward-forward passes.
Abbeel & Ng (2004) ICML '04
Apprenticeship Learning via Inverse Reinforcement Learning
\(\mathcal{M} = \langle \mathcal{S}, \mathcal{A}, \mathcal{P}, \gamma, \mathcal{R}=w^T\phi \rangle\)
\(\mathcal{S}\)
State Space: Finite MDP states with a known feature map \(\phi(s)\).
\(\mathcal{A}\)
Action Space: Finite action set.
\(\mathcal{P}\)
Transitions: Known transition model.
\(\mathcal{R}\)
Reward Function: Linear \(w^T\phi(s)\) with \(\lVert w \rVert \le 1\).
\(\pi^*\)
Policy Objective: Find a policy whose discounted feature expectations \(\mu(\pi)\) match the expert's \(\mu_E\); returns a mixture of policies.
Wulfmeier et al. (2015) arXiv
Maximum Entropy Deep Inverse Reinforcement Learning
\(\mathcal{M} = \langle \mathcal{S}, \mathcal{A}, \mathcal{P}, r_\psi \rangle\)
\(\mathcal{S}\)
State Space: Grid cells with raw feature maps as network input.
\(\mathcal{A}\)
Action Space: Grid moves.
\(\mathcal{P}\)
Transitions: Known (deterministic) dynamics in the benchmarks.
\(\mathcal{R}\)
Reward Function: Neural network \(r_\psi(s)\) in place of a linear reward.
\(\pi^*\)
Objective: MaxEnt likelihood; gradient with respect to \(\psi\) is obtained by back-propagating (expert minus expected state visitation) through the network.
McFadden (1974) / route-choice logit Econometrics
Conditional Logit over a Route Choice Set
\(\mathcal{M} = \langle \mathcal{C}_{od}, V_i = \beta^T x_i \rangle\)
\(\mathcal{S}\)
State Space: None: a one-shot choice for each origin-destination pair.
\(\mathcal{A}\)
Action Space: A generated set of complete candidate routes \(\mathcal{C}_{od}\).
\(\mathcal{P}\)
Transitions: Not modelled.
\(\mathcal{R}\)
Utility: Linear \(V_i = \beta^T x_i\) in route attributes (time, distance, turns), with optional path-size correction.
\(\pi^*\)
Choice Rule: \(P(i) = e^{V_i} / \sum_{j \in \mathcal{C}} e^{V_j}\).
Dijkstra / A* (1959, 1968) Classical
Single-Metric Shortest / Fastest Path Search
\(\mathcal{M} = \langle V, E, \mathcal{P}_{\text{det}}, -c(e), v_{dest} \rangle\)
\(\mathcal{S}\)
State Space: Graph nodes \(v \in V\).
\(\mathcal{A}\)
Action Space: Outgoing directed edges \(e=(u,v)\).
\(\mathcal{P}\)
Transitions: Deterministic: \(P(v \mid u, e) = 1\).
\(\mathcal{R}\)
Cost / Reward: Fixed \(-c(e)\) with \(c\) = length or length/speed.
\(\pi^*\)
Optimal Policy: \(\arg\min \sum_{e \in \tau} c(e)\) found by priority-queue search.
⭐ This project: Edge-State MaxEnt IRL THIS PROJECT
Exact Linear-Reward Route Preference Learning
\(\mathcal{M} = \langle \mathcal{S}=E\times\{d\}, \mathcal{A}, \mathcal{P}, \mathcal{R}_{\mathbf{w}}, \gamma=1 \rangle\), \(H=80\)
\(\mathcal{S}\)
State Space: The incoming directed edge \(e_{t-1}=(u\to v,k)\) with a fixed destination \(d\). It fixes both the current node and the heading, so turn angle is a function of (state, action).
\(\mathcal{A}\)
Action Space: \(A(e)=\{e' : \text{tail}(e')=\text{head}(e)\}\) (about 2–4 roads); U-turns allowed but penalised.
\(\mathcal{P}\)
Transitions: Deterministic: \(P(s'=a\mid s,a)=1\). Terminal when \(\text{head}(e)=d\), with \(V=0\).
\(\mathcal{R}\)
Feature Vector: \(\mathcal{R}_{\mathbf{w}}(e,e')=\mathbf{w}^T\phi(e,e')\) with 11 features: length, travel time, per-step constant, motorway, primary, slight turn, sharp turn, lanes, same-road continuation, away-from-goal, edge familiarity. w is unknown and learned.
\(\pi^*\)
Soft Bellman: \(V(e)=\log\sum_{e'} \exp Q(e,e')\), \(\pi(e'\mid e)=\exp(Q-V)\); exact backward and forward passes, no sampling. The single most likely route is extracted with Viterbi/Dijkstra on \(V-Q\).

🧭 What This Project Contributes (and What It Does Not)

The contribution is an open, careful application and evaluation of known methods; the points below separate what is new here from what is inherited from prior work.

🔄

1. Heading Lives in the State

With a node-only state the incoming bearing is lost, so a turn cost is not a function of (state, action). We use the incoming edge as state: \(\mathcal{S}=E\), which keeps turn features Markov. This is a modelling choice, not a new idea: Ziebart et al. also use turn-type features.

Edge-State MDP
📊

2. Exact Gradients, No Sampling

Expected feature counts come from finite-horizon soft value iteration plus an exact forward pass, so \(\nabla = \mathbb{E}_\pi[\phi] - \phi_{\text{expert}} + \lambda w\) has no Monte-Carlo noise. This follows the original MaxEnt IRL algorithm; the cost is about 13 minutes per CV fold on CPU.

Exact, Shared with Ziebart
🔍

3. Readable Weights

The reward is linear, so weights can be read directly. On Porto (v3, single split): sharp turn −1.46, slight turn −0.52, away-from-goal −0.29, per-step −0.67, edge familiarity +0.87. Note that length and travel time are correlated (r = 0.81), so individual weights should be read together; we therefore do not report a value-of-time figure.

Interpretable, with Caveats
🔓

4. Open, Reproducible Pipeline

Everything uses public assets: the Porto taxi data (ECML/PKDD 2015), OpenStreetMap, and HMM map matching. Only 40% of attempted trips could be matched (3,000 of 7,528), and matching errors are treated as ground truth.

Open Data & Code
🧩

5. Identifiable Features + Familiarity

The first feature set had collinear features and lost to Dijkstra-Shortest (F1 0.611 vs 0.636). We dropped reference levels, added a per-step constant, same-road and away-from-goal features, and a familiarity feature estimated on an independent trip pool, lifting F1 to 0.659 raw and 0.682 after a validation-chosen length penalty.

v1 → v3
📈

6. Honest Empirical Results

On 600 held-out trips: IRL 0.682 vs Shortest 0.636 (paired p = 2.7e-5), Fastest 0.454, myopic 0.162; Top-1 junction accuracy 93.7%. In 5-fold CV: 0.669 ± 0.010 vs 0.630 ± 0.003, but a popularity-weighted shortest path scores 0.671, so the gain is modest and partly due to the familiarity signal.

Modest, Significant Gain
